📰 Project Overview – "Asioso" Website
Asioso News is a responsive and basic news aggregator website built with React.js, designed to fetch and display real-time news articles using two different News APIs (e.g., NewsAPI.org, The New York Times API, etc.).

The project demonstrates how to integrate multiple external APIs, handle asynchronous data fetching with React hooks, and display content in a clean, user-friendly layout.

🔧 Key Features
🌐 Live News Feed – Fetches the latest headlines from two different APIs.

🔄 API Integration – Uses fetch() or axios to retrieve and combine data from multiple sources.

🧩 Category Filters – View articles by category (e.g., Technology, Business, Sports).

🔍 Search Functionality – Search for news articles by keyword.

📱 Fully Responsive – Mobile-first design that adapts across devices.

⚛️ React Hooks – Utilizes useEffect, useState, and conditional rendering.

🔗 Clickable Articles – Each news item includes a title, image, short description, and a link to the full article.
